# Task Generator

As a university student tutoring 9th graders in math and computer science, I needed a way to quickly generate fresh, varied, and challenging practice problems for their tests. This script automates that entire process.

## Overview
Instead of manually writing tests every week, this tool takes predefined templates and rulesets, randomizes parameters, and outputs ready-to-print assignments and solutions. It saves hours of preparation time while ensuring students get unique tasks tailored to their current curriculum.

## Features
*   Generates dynamic mathematical equations and logic problems.
*   Creates customized IT and programming exercises (including basics of version control/GitHub).
*   Outputs both the student test sheet and the teacher's answer key.

## Usage
Simply run the main script and specify the module you want to generate tasks for.
